# 🩺 Dr. Silva — Nutrologia

Site de demonstração de portfólio profissional para **profissional liberal da
saúde**: apresentação do médico, serviços com preços, depoimentos de pacientes
e agendamento direto via WhatsApp.

> 📄 Demo publicada: [VER AQUI](https://SEUUSUARIO.github.io/PORTIFOLIO/demos/dr-silva-nutrologia/)

## 🎯 Objetivo do projeto

Terceiro projeto de demonstração do portfólio — foco em portfólio
profissional com tom sóbrio e minimalista (tema azul/branco, tipografia
serifada), contrastando com as duas demos anteriores para mostrar
amplitude visual e de repertório.

## ⚙️ Funcionalidades

- Seção "Sobre" com credenciais e espaço para foto profissional
- Grade de serviços com preços (consulta, plano alimentar, acompanhamento)
- Depoimentos de pacientes
- Botão de agendamento direto no WhatsApp (sem formulário — padrão em sites médicos)
- Aviso de responsabilidade médica no rodapé
- Layout responsivo
